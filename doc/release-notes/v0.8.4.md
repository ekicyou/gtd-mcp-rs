### Git sync works with HTTPS remotes that use a credential helper (#258)

In `--sync-git` mode, fetch and push now ask Git's credential helpers for
credentials, for example the GitHub CLI helper set up by `gh auth setup-git`.
Previously, such an HTTPS remote failed with an authentication error (401).
No configuration change is needed. If you switched to an SSH remote to work
around the problem, you can keep using it.

### Releases are published from CI with a smaller package (#260, dbe9713)

Releases are now published to crates.io by a GitHub Actions workflow when a
version tag is pushed. The published package contains only the source code,
`Cargo.toml`, `Cargo.lock`, `README.md`, and `LICENSE`, and the dependency
versions in `Cargo.lock` are the ones tested in the repository. Installing
with `cargo install gtd-mcp` works as before. Release notes for this and later
versions are in `doc/release-notes/` in the repository and on the GitHub
Releases page; `RELEASE.md` covers versions up to 0.8.0.

### Internal maintenance (#257, #259)

Development tooling was updated. There is no change to the server's behavior
or to its data files.
